Towards Spatial-Temporal Grounded Vision-Language-Action Models

A progressive framework for bridging 3D perception, temporal memory, and physically grounded action generation in embodied AI.

TL;DR

We identify three key bottlenecks in current VLA systems: missing 3D geometric priors, missing temporal memory, and weak grounding from semantic reasoning to physical action. To address them, we propose a three-layer framework based on spatiotemporal memory, a spatially enhanced VLM backbone, and 3D-grounded training data.

Highlights

  1. Spatiotemporal Memory. Explicit history aggregation improves long-horizon execution and state tracking.
  2. Spatially Enhanced Backbone. RynnBrain-8B strengthens spatial reasoning and object localization.
  3. 3D Grounded Training. Point/depth-aligned supervision helps bridge semantic reasoning and physical coordinates.
  4. Modular Evaluation. StarVLA enables controlled comparison across backbones, modules, and data settings.

Three-layer progressive design: memory module, spatial backbone, and 3D grounded training.

Layer 1: Spatiotemporal Memory

Introduce explicit memory into the visual encoder so the model can retain object trajectories, track interaction history, and reason over long-horizon tasks.

Layer 2: Spatially Enhanced VLM

Replace the generic VLM base with a stronger spatial foundation model to improve geometric understanding and coordinate-sensitive reasoning.

Layer 3: 3D Grounded Training Data

Integrate depth or point-based information into training so the model learns to align semantics with physically meaningful coordinates.

Engineering Platform

The framework is implemented on StarVLA for clean backbone replacement, modular integration, and controlled ablation on embodied benchmarks.
