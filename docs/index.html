About

StarVLA is a modular and flexible codebase for developing Vision-Language Models (VLM) into Vision-Language-Action (VLA) systems. It emphasizes plug-and-play design, rapid prototyping, and independent debugging.

Highlights

  • Modular VLA development framework
  • Support for multiple Qwen-based VLA variants
  • Examples, deployment scripts, and assets included
  • Designed for fast experimentation and extension
