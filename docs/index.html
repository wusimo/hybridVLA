Towards Spatial-Temporal Grounded Vision-Language-Action Models

A three-stage research roadmap for bridging 3D perception, temporal memory, and physically grounded action generation in VLA systems.

Abstract

Vision-Language-Action (VLA) models have become a mainstream paradigm for embodied AI, aiming to map visual observations and language instructions directly to robot actions. Our work focuses on the VLM-to-VLA evolution route and identifies three major bottlenecks: lack of intrinsic 3D geometry in 2D visual tokens, lack of temporal memory in reactive decision-making, and the gap between high-level semantic reasoning and precise physical action.

To address these issues, we propose a three-layer progressive framework: (1) a spatiotemporal memory module for long-horizon context retention, (2) a spatially enhanced VLM backbone based on RynnBrain-8B, and (3) explicit integration of 3D point/depth information into VLM training, enabling semantic reasoning to be grounded in physical coordinates.

Project Motivation

Bottleneck 1

2D Perception Trap

Standard visual tokens do not carry explicit 3D geometry, which harms precise spatial reasoning in fine-grained manipulation.

Bottleneck 2

Reactive Memory Failure

Current VLA models are often frame-reactive and cannot maintain long-horizon task context or track object state transitions.

Bottleneck 3

Semantic-to-Physical Gap

Strong language understanding does not automatically translate into millimeter-level motion precision in 3D space.

Method Overview

We develop a three-stage progressive solution where each layer addresses one core bottleneck, while the layers reinforce each other to build a unified spatial-temporal VLA framework.

Method Figure Placeholder Suggested: 3-stage architecture diagram
01

Spatiotemporal Memory Module

Introduce explicit historical context aggregation into the visual encoder, allowing the model to remember object trajectories, prior interactions, and long-horizon execution states.

02

Spatially Enhanced VLM Backbone

Replace the generic backbone with RynnBrain-8B to inject stronger spatial reasoning, object localization, and coordinate-aware understanding into the base model.

03

3D Grounded Training Data

Integrate point cloud or depth-aligned 3D information into training so that the model learns to reason directly in physical coordinates instead of relying only on implicit action translation.

Why This Design

Engineering Platform

We build on StarVLA, a modular Lego-like VLA framework that supports backbone replacement, custom modules, unified data pipelines, and controlled ablation experiments.

Controlled Comparison

The framework makes it easy to compare Qwen3-VL, Qwen3-VL + memory, RynnBrain-8B, and RynnBrain-8B + memory under the same training and evaluation pipeline.

Current Progress

Qwen3-VL + Memory Module

Initial evaluation has been completed to isolate and verify the benefit of temporal memory for long-horizon task execution.

RynnBrain-8B Integration

Integration into the StarVLA framework is already running end-to-end. Full training and complete evaluation are the next steps.
